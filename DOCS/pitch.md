A mobile app for deaf and hard-of-hearing people to read captions on their own device when the source (a cinema screening, a car radio, a live speaker, etc.) doesn't provide any.

There is no audio or video played by the app — it only displays a subtitle file (.srt, .vtt, .ass, .ssa, or other common formats) that the user imports themselves. Make sure permissions are required where the OS demands them.

A simple play button starts a stopwatch, with a bar showing elapsed/total time.

The text of the current subtitle line is shown based on the stopwatch's time, so the user can follow along by starting the stopwatch when the movie/audio starts.

Since the stopwatch can drift out of sync with the actual source over time, the user can nudge it forward or back to the previous/next line to resync.

The app should work and resize either in background or portrait mode.

The stopwatch should keep running in the background if the screen is off or the app is minimized (e.g. phone in a pocket during a movie).

There should be a menu in the notifications bar showing the current caption and stopwatch controls.

People can stop the stopwatch through either the app or the notification bar section.

People can import their own subtitle files.
