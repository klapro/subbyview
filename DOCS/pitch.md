A mobile app
Allows people to be able to read subtitles files with .srt and .vtt or .ass .ssa or any other subtitles format to import files. Make sure permissions are required.
A simple play button with a bar for the time.
Text of the subtitles should be shown with the current time.
The app should work and resize either in background or portrait mode.
The player should still work in the background if a track is played.
There should be a menu in the notifications bar that shows that the track is being played.
People can stop the track through either within the app or within the menu bar section
People can import their own subtitles files
